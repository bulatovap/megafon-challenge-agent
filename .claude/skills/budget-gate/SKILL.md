# Бюджет шага на исходе

1. Не начинай новых проверок. Запусти `python3 -m tools.bulochka budget ask` и покажи продакту вопрос и варианты
   как есть: каждое непроверенное C### с ценой проверки, «поднять бюджет до N», «остановиться».
2. Жди ответа. Записывай его дословно: `python3 -m tools.bulochka answer G### --answer "…"`. Молчание — «остановиться».
3. `python3 -m tools.bulochka budget resolve G###` и действуй по его выводу:
   - C### — проверяешь только это утверждение (`bulochka verify C###`, при нужде одна загрузка источника);
     отложенные не трогаешь; когда хук скажет «проверено — останавливаюсь», делаешь `bulochka receipt` и `bulochka pause`;
   - «поднять» — продолжаешь шаг с новым бюджетом;
   - «остановиться» — квитанция уже записана: покажи продакту разделы «Готово», «Уже можно пользоваться»
     и команду продолжения.
4. Бюджет сам не поднимаешь и отказ не обходишь: решение о цене — за продактом.
