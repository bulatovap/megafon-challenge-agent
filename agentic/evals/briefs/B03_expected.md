# B03_expected — ключ для проверяющих к брифу «B03. Позиционирование собственного бренда смартфонов»

Ключ к учебному брифу `knowledge/briefs/B03.md`: там — только запрос продакта и материалы, чтобы агент не видел
ожидаемый ответ и ловушки. Этот файл лежит в документации, куда агент по инструкциям не заходит.

## Что ожидается на выходе

- Позиционирование по Данфорду: альтернативы (включая «купить известный бренд» и «не менять
  телефон») → уникальные атрибуты → ценность с доказательством → кому → категория.
- Барьеры «не верю» и «не вижу разницы»; почему «лучший за свои деньги» их не снимает.
- Тест «обещание → свойство продукта или запись реестра»: каждое обещание кампании подтверждено
  характеристикой или отзывами, иначе — убрать.
- Роль каналов: салоны и личный кабинет оператора как физическая доступность, широкие медиа —
  отдельно.
- Варианты включают «оставить бренд без кампании» и «свернуть собственный бренд».
