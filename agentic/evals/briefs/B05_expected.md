# B05_expected — ключ для проверяющих к брифу «B05. Экосистемный тариф «связь + подписка» против чистой медиаподписки»

Ключ к учебному брифу `knowledge/briefs/B05.md`: там — только запрос продакта и материалы, чтобы агент не видел
ожидаемый ответ и ловушки. Этот файл лежит в документации, куда агент по инструкциям не заходит.

## Убрано из брифа

Убрано из контекста брифа (подсказки агенту): «колонка 2022 г. — только как история»; «Цифры „продуктов на экосистемного клиента“ в открытых источниках нужно сверять по определению: компании считают их по-разному».

## Что ожидается на выходе

- Цепочка «польза подписки → удержание абонента → ARPU и отток» с явными допущениями;
  каннибализация как отдельный расчёт (кодом).
- Варианты: оставить медиаподписку отдельно / тариф-бандл / подписка как опция к старшим
  тарифам / закрыть подписку — различаются моделью дохода.
- Guardrail'ы: ARPU по тарифам, миграция вниз по линейке.
- План проверки: ступенчатый запуск по регионам вместо A/B на всей базе, сравнение с соседним
  регионом, срок с учётом цикла смены тарифа.
- Предупреждение о несопоставимых метриках: «экосистемный клиент» у разных компаний — разное.
