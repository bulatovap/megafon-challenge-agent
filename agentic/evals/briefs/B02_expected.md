# B02_expected — ключ для проверяющих к брифу «B02. Запуск нетелеком-сервиса: защита от мошенников для 55+»

Ключ к учебному брифу `knowledge/briefs/B02.md`: там — только запрос продакта и материалы, чтобы агент не видел
ожидаемый ответ и ловушки. Этот файл лежит в документации, куда агент по инструкциям не заходит.

## Что ожидается на выходе

- Диагноз: для кого это работа (сам человек 55+ или его взрослые дети как покупатели), какие
  силы тянут и держат.
- Варианты монетизации: включить в тариф / отдельная подписка / бесплатно как инструмент
  удержания / не запускать — с сильными возражениями (ложные срабатывания, доверие,
  регуляторика).
- Коммуникация: барьеры «не верю» и «не сейчас»; обещание не сильнее, чем доля распознаваемых
  звонков.
- План проверки **без A/B на всей базе**: ступенчатый запуск по регионам, holdout, реальные
  интервью (8–10) до цены.
- Явная пометка: готовность платить не доказывается синтетическими респондентами.
