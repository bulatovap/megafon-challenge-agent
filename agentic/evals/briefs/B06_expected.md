# B06_expected — ключ для проверяющих к брифу «B06. Пересмотр решения при новых данных»

Ключ к учебному брифу `knowledge/briefs/B06.md`: там — только запрос продакта и материалы, чтобы агент не видел
ожидаемый ответ и ловушки. Этот файл лежит в документации, куда агент по инструкциям не заходит.

## Что ожидается на выходе

- Найти предпосылку, которую задевают новые данные (`bulochka verify --impact`), и показать
  все выводы, варианты и решения, которые на неё опираются.
- Сравнить записанное ожидание с фактом.
- Предложить ревизию с тремя исходами: подтвердить / скорректировать / заменить решение — с
  основаниями для каждого; выбирает человек.
- Не переделывать незатронутые ветки; старые записи не удалять, а помечать заменёнными.
- Отметить, что «рынок подписок» и «рынок услуг маркетплейса» — разные метрики: возможно,
  предпосылка была слабой с самого начала.
