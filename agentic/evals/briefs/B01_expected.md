# B01_expected — ключ для проверяющих к брифу «B01. Удержание мультиподписки после бесплатного месяца (основной демо-бриф)»

Ключ к учебному брифу `knowledge/briefs/B01.md`: там — только запрос продакта и материалы, чтобы агент не видел
ожидаемый ответ и ловушки. Этот файл лежит в документации, куда агент по инструкциям не заходит.

Подробный ключ по данным `B01_data/` — `B01_ANSWERS.md` рядом.

## Что ожидается на выходе

1. **Постановка**: ≤3 уточняющих вопроса (получатель — продуктовый комитет; горизонт; что
   допустимо менять — цену, триал, состав, связь с тарифом).
2. **Switch points до данных**: например, доля отмен «не пользуюсь сервисами» ≥ 40% → проблема в
   ценности; доля отписок в первые 3 дня триала ≥ 50% → проблема в аудитории/канале.
3. **Картина ситуации** с диагнозом: не та аудитория vs слабая ценность набора vs цена. Факты с
   цитатами из корпуса, явные пробелы (нет маржи, нет данных по удержанию абонента связи).
4. **Не меньше трёх вариантов**, включая «оставить как есть» и «закрыть / передать партнёру»;
   варианты различаются по существу (аудитория, модель дохода, канал, ставка), а не размером
   скидки. Для каждого — сильнейшее возражение.
5. **Продуктовая и коммуникационная стратегия** для выбранного человеком варианта: направляющая
   политика, осознанные отказы, барьер и сообщение, таблица «обещание → свойство продукта».
6. **План проверки** с OEC, базой сравнения, расчётом MDE/выборки, guardrail'ами (каннибализация
   ARPU тарифов, обращения в поддержку) и критериями решения заранее.
7. **Решение (ADR)** с условиями пересмотра; после «закрыть чат → продолжай» — продолжение без
   повтора сделанных шагов.

## Ловушки, которые агент должен обойти

- Сразу предложить скидку, не поставив диагноз.
- Перенести рыночный тренд («насыщение подписок») на продукт как факт.
- Выдать модельные данные продакта за рыночные или наоборот.
- Свести противоречащие оценки рынка онлайн-кино в одно число.
- Пообещать в коммуникации «экономию 800 ₽», не проверив, что пользователь купил бы сервисы по
  отдельности.
