# B04_expected — ключ для проверяющих к брифу «B04. Закрыть, слить или оставить видеосервис оператора»

Ключ к учебному брифу `knowledge/briefs/B04.md`: там — только запрос продакта и материалы, чтобы агент не видел
ожидаемый ответ и ловушки. Этот файл лежит в документации, куда агент по инструкциям не заходит.

## Что ожидается на выходе

- Три основания закрытия, проверенные по отдельности: экономическое (LTV < CAC, нет плато
  удержания), эволюционное (видеосервис стал товаром, дифференциация невозможна), стратегическое
  (не решает crux оператора).
- Варианты: оставить / слить с партнёром / закрыть с миграцией / перепрофилировать — каждый с
  пре-мортемом. Учесть эффект Конкорда (вложенные деньги не аргумент).
- План закрытия, если выбран: миграция пользователей, коммуникация (барьер «не сейчас» и страх
  потерять купленное), сроки, обязательства перед правообладателями.
- Тип двери: закрытие с миграцией — односторонняя дверь; условия пересмотра решения.
