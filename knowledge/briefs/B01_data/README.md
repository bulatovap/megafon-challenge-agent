Материалы продакта к брифу `B01.md` (мультиподписка 399 ₽, первый месяц бесплатно).
Данные по октябрь 2026 включительно. Строки, начинающиеся с `#`, — комментарии
(в pandas: `pd.read_csv(f, comment="#")`).

| Файл | Что внутри | Определения |
|---|---|---|
| `cohorts.csv` | 12 месячных когорт (2025-10 … 2026-09) × 3 канала привлечения: органика, партнёры, промо. Начали триал → оплатили M0 → активны M1…M6 | когорта = месяц начала триала; `mk` — активные платные на конец k-го **календарного** месяца после M0; удержание = `mk / paid` (знаменатель — оплатившие) |
| `cancel_reasons.csv` | отписки по месяцу начала триала, каналу, причине и дню отписки от начала триала (0–3, 4–14, 15–30) | окно — **30 дней от начала триала**; знаменатель — `trials_started` (все начавшие триал); отключение автопродления в триале считается отпиской |
| `nps.csv` | NPS активных платных подписчиков по кварталам и каналам | опрос в приложении, ушедшие не опрашиваются; пустая строка — опрос не проводился |

Пустая ячейка = нет данных. В когортах пустой хвост ряда означает, что когорта ещё не дожила до этого месяца.

## Как считать

Числа не считай в уме — запускай `scripts/calc.py` из корня проекта и записывай вывод с `plan_hash`:

```bash
python3 scripts/calc.py cohort --csv knowledge/briefs/B01_data/cohorts.csv          # таблица удержания, разрыв каналов, форма кривой
python3 scripts/calc.py cohort --csv knowledge/briefs/B01_data/cohorts.csv --json   # то же в JSON
```

Для `cancel_reasons.csv` и `nps.csv` отдельной подкоманды нет — считай коротким `python3`-скриптом
и записывай вывод как `claim add --type inference` со ссылками на исходные C###.

Перед сравнением чисел из разных файлов сверь определения метрик (окно и знаменатель) — они
указаны в шапке каждого файла.
